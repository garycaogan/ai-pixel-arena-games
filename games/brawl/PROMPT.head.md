# AI 像素擂台：像素拳斗

请提交一个仅使用 Python 标准库的 `bot.py`，实现 `decide(state) -> str`。这是一个 1 对 1 的 2D 格斗游戏：一帧就是一回合，每秒 {{FPS}} 帧，两名选手每帧同时交一个动作。非法、缺失、异常或超时的动作按 `n`（站着不动）处理。这份文档是完整的规则和公开状态合同。

## 选角

第 1 帧 `state["phase"] == "select"`，请返回四个角色代号之一：`lie`（阿烈，均衡）、`tie`（铁山，投技）、`yan`（飞燕，速度）、`rei`（雷娜，远程）。两人同时选，看不到对方的选择，可以选同一个角色。返回别的值就按种子随机抽一个。之后每局都用这个角色。

## 赛制

三局两胜。每局开始先有 {{INTRO}} 帧开场（`phase="intro"`，动作无效），然后 `phase="fight"` 计时 45 秒；一方血量归零就 K.O.，这局结束；时间到时比剩余血量**比例**（`hp / max_hp`），高的赢，完全相同则这局双方都不得分；同一帧双方都归零（双倒）也都不得分。每局结束后有 {{OUTRO}} 帧收尾（`phase="end"`，动作无效，物理继续），然后双方血量、气以外的状态全部重置，回到起点 x={{X0}} 和 x={{X1}} 开下一局。**气（meter）跨局保留**。先赢 2 局的赢下比赛；最多打 5 局，打完还平就是平局。

## 场地和坐标

横轴 x 从 0 到 {{STAGE_W}}，左右墙在 x={{WALL}} 和 x={{STAGE_W}}−{{WALL}}，角色中心不能出墙。y 是脚底离地高度，地面是 0，向上为正。`face` 是朝向，1 朝右、−1 朝左。站在地上（`stand`、`walk`、`crouch`）时每帧自动转向面对对手。两人中心距离小于 {{PUSH_W}} 时互相推开（一方高过 30 或被投时不推）。

## 反应延迟

你的 `state["me"]` 是当前帧的真实状态；`state["opp"]` 是**对手 {{DELAY}} 帧前**的状态（约 0.2 秒）。对手的飞行道具同样晚 {{DELAY}} 帧，自己的飞行道具是当前位置。起手比 {{DELAY}} 帧短的招，你看见时它往往已经打中了。

## 动作

| 动作 | 含义 |
| --- | --- |
| `n` | 站着不动 |
| `f` | 向前走（朝对手） |
| `b` | 向后走，同时**站防**（挡中段和上段） |
| `d` | 蹲下 |
| `g` | 蹲着**蹲防**（挡中段和下段） |
| `u` / `j` / `y` | 原地跳 / 前跳 / 后跳：先 3 帧起跳（这 3 帧在地上，不能被投），再离地 |
| `r` | 前冲（固定帧数，中途不能出招） |
| `e` | 后撤步，开头几帧无敌 |
| `p` `h` `k` `s` | 轻拳、重拳、脚、扫腿 |
| `t` | 投 |
| `z` | 必杀技 |
| `a` | 对空技 |
| `x` | 超必杀（耗 100 气） |

只有站在地上（`stand`、`walk`、`crouch`）的帧才能开始新动作；出招、跳、冲、硬直、倒地时按什么都不改变当前动作（下面两种例外）。

- **防御要每帧按住：**防御状态每帧清零，只在这一帧按了 `b` 或 `g` 才算在防。防住以后进入防御硬直，硬直期间按 `b`/`g` 可以换站防/蹲防，不按就维持上一次的防法。
- **取消：**`cancel` 的招（各角色的轻拳、重拳）打中或被防住以后，从招式第 1 帧算起到 起手+判定+4 帧以内，按 `z`、`a`、`x` 会立刻改出那一招（够条件的话）。
- **跳攻：**在空中按 `p`、`h` 或 `k` 出一次跳攻（每次跳只能出一次），起手从按下那帧算起，落地就结束。
- 用不了的招（气不够；或者自己已经有一个飞行道具在场上时再按放波的招）按了等于 `n`。

## 每帧结算顺序

1. 站在地上的人转向对手。
2. 两人的动作同时生效（上面的规则）。如果有人这一帧开始超必杀，全场定格 18 帧：这 18 帧双方动作无效、计时不走，定格结束后从起手第 1 帧继续。
3. 双方按状态移动（走、跳、冲、招式自带位移、硬直后退、被投轨迹）。
4. 推开。
5. 飞行道具前进；双方飞行道具相碰就一起消失（雷娜的超必杀光束碰到普通飞行道具时只消掉对方，自己继续）。
6. 判定：投、打击、飞行道具同时计算，用的都是这一帧结算前的状态。招式在起手之后的判定帧里，判定框（横向范围从身体中心朝前算、高度从脚底算）和对方受击框（中心 ±11，高度为站高；蹲姿和扫腿时为蹲高；空中为 56）有重叠就打中；无敌时打不中。多段招每段一次。新飞行道具在起手后一帧生成在身前 22 处，高度见招式表。
7. 双方都不在防御、不在防御硬直时，防御值每帧回 0.25。计时减 1 帧；有人血量归零或时间到就结束这一局。

## 打中、防住和投

- **防住**：要站在地上、处于 `stand`/`walk`/`crouch`/`blockstun`、这一帧在防，而且防法对：中段站防蹲防都能挡，下段（扫腿）只能蹲防，上段（跳攻）只能站防。防住进入防御硬直（`bs` 帧），被削血（`chip`，削不死，最少留 1 血），防御值减少 伤害×0.45；防御值降到 0 就**破防**：直接硬直 42 帧，防御值回满（上限 {{GUARD_MAX}}）。
- **打中**：对方在出招起手阶段被打中算**反击**，伤害 ×1.25，硬直 +4 帧（轻拳反击不加硬直）。连击里伤害按 max(0.4, 1 − 0.15×已挨的连击数) 递减（超必杀最低 0.7 倍）；硬直为 max(6, 招式硬直 − 2×(这一下是第几击 − 1))。打中或防住贴墙的人时，攻方会被往回推一点，墙角不能无限压。击倒的招或打中空中的人会把人打倒：倒地 34 帧，起身 10 帧，倒地和起身期间无敌。
- **铁山的重拳**起手前段可以硬吃一下（照样掉血、不被打断，超必杀除外）。
- **投**：判定帧里两人中心距 ≤ 抓取距离、对方在地上、不在空中、起跳、硬直、倒地、起身、被投、正在投、无敌中，就抓到；投防不住。双方同一帧投对方就**拆投**：都退开，各自硬直 10 帧。投的人在同一帧挨了打就投不出。被投的人飞 20 帧落地，再倒地 30 帧。指令投（`cmd`）是必杀技或超必杀形式的投。
- **气**：打中、被打、防住、被防都会涨气，上限 {{METER_MAX}}（3 格），超必杀耗 100。

## state 逐项说明

选角帧（`phase="select"`）：`turn`（=1）、`phase`、`you`（0 或 1）、`chars`（四个代号）、`stage_w`、`wall`、`delay`、`fps`、`round_seconds`、`rounds_to_win`。

之后每帧：

| 字段 | 含义 |
| --- | --- |
| `turn` | 即将结算的帧号（全场累计，从 1 开始，含开场收尾和定格） |
| `phase` | `intro`、`fight`、`end`；只有 `fight` 时动作有效 |
| `you` | 你的座位 0 或 1 |
| `round` | 第几局，从 1 开始 |
| `timer`、`timer_frames` | 本局剩余秒数（向上取整）和帧数 |
| `score` | `[你赢的局数, 对手赢的局数]` |
| `me` | 你现在的状态（下表） |
| `opp` | 对手 {{DELAY}} 帧前的状态（下表） |
| `projectiles` | 场上飞行道具：`{mine, x, y, vx, w, look}`；`y` 只用于画面，判定高度看招式表，`look` 为 `fire`（阿烈）、`bolt`（雷娜）、`beam`（雷娜超必杀）；对手的是 {{DELAY}} 帧前的位置。判定高度见招式表 |
| `freeze` | 超必杀定格剩余帧数，大于 0 时动作无效 |
| `stage_w`、`wall`、`delay`、`fps`、`round_seconds`、`rounds_to_win` | 常量 |

`me` / `opp` 的字段：

| 字段 | 含义 |
| --- | --- |
| `char` | 角色代号 |
| `x`、`y`、`vx`、`face` | 位置、横向速度、朝向 |
| `st` | `stand` `walk` `crouch` `prejump` `air` `land` `dash` `backdash` `attack` `throw`（正在投人） `thrown`（被投） `hitstun` `blockstun` `knock`（倒地中） `wake`（起身） `ko` `win` |
| `mv` | 正在出的招（`p` `h` `k` `s` `t` `z` `a` `x`，空中是 `air`），没有为 null |
| `mf` | 这招已经进行到第几帧 |
| `phase` | `startup`、`active`、`recovery` 或 null |
| `stun` | 硬直或倒地剩余帧数 |
| `hp`、`max_hp` | 血量 |
| `meter` | 气，0..{{METER_MAX}} |
| `guard` | 防御值，0..{{GUARD_MAX}} |
| `combo` | 正在挨的连击数 |
| `inv` | 这一帧是否无敌 |
| `gmode` | 这一帧的防法 `high`、`low` 或 null |
| `contact` | 当前这招是否已经打中或被防（取消要看它） |

## 进程与 CPU 限制

Python 3.13，仅标准库，提交一个文件。每场比赛新加载一次，模块全局变量在这场比赛里一直保留（跨局也保留），比赛之间清零。裁判按种子初始化 `random`。加载限 1 秒 CPU，第 1 帧限 1 秒 CPU，以后**每帧 50 毫秒 CPU**，另有每次回复 3 秒墙钟兜底。一场比赛最多几千帧，请让每帧的计算保持轻量。异常、超时、非法返回按 `n`，连续三次失败或进程未响应会结束该进程，本场后续都按 `n`；一次成功回复清零连续失败次数。沙箱禁止读写文件、联网、开子进程，print 不参与协议。

交卷只放一个完整 Python 代码块，后附简短策略说明。
