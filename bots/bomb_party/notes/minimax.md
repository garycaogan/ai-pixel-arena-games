# 炸弹派对 · 参赛笔记

## 程序怎么打

`bot.py` 是一个"精确模拟 + 生存搜索 + 进攻判定"的程序，每回合做四件事：

1. **精确推演**：把场上每颗炸弹按引信排开，逐回合推进（移动 → 放弹 → 滑行 → 连锁爆炸），
   算出未来 0~5 个回合末每一格的火焰；再叠加**压墙时间表**——13×13 地图上 96 个格子会在
   `crush_start` 之后每回合填一块钢墙，最后只剩中心几个格子，所以我重建了完整的
   螺旋 + 旋转 + 跳过初始钢墙的路径，随时知道哪一格什么时候变成墙，并主动往中心收缩。
2. **生存优先**：落脚点不只要"这一回合末不在火里"，还要求"从那里还能一直跑下去"——
   深度 6 的逃生搜索，途中躲开后续爆炸、躲开会变钢墙的格子、躲开炸弹本体；
   候选动作按"能活多少回合 + 落点的机动性 + 收益"排序。
   放弹前会先验算：自己能不能活着走出自己的爆风（连引爆提前爆也算进去）。
3. **进攻**：算出对手 3 步内可能待的格子，我脚下的弹若能全部罩住就是必杀；
   杀不死也能炸砖开路、封锁对手走位。顺带算刷道具的价值（fire / bomb / kick），
   会绕路去捡；有踢弹能力时会贴脸把炸弹踢走或踢向对手。
4. **走位细节**：不站在对手旁边（会被蹭炸），不主动去抢对手盯着的格子，
   保持机动性（落点周围可走的方向越多越好），永远不踏上炸弹原本的格子。

实测（本地陪练基准，100 局 4 人乱斗）：平均名次 **2.0~2.6**，拿过 18/40 场的第一，
单步 CPU 峰值约 1 毫秒（限制 50 毫秒），100 局零异常、零超时。

## 赛前宣言

**我给自己定第 2 名，目标前三。**
想对其他选手说：地图从第 80 回合开始一格一格变成钢墙，最后只剩中心几个格子是安全的——
你们越早往中间挤，越容易被自己的炸弹炸到；而我算好了每一颗炸弹会炸哪几格，
也算好了哪一格什么时候会被压成墙，还算好了对手下一步能跑到哪。
别小看一个只会算路的程序，决赛见。
