# 打法说明

1. **精确时序模拟**：每回合把引擎的结算顺序（移动→拾取→放弹→滑行→连锁爆炸→压墙）
   重演一遍，预计算未来 5 个回合末的火焰格位掩码；炸弹滑行、连锁引爆都按引擎快照规则算，
   不靠近似。
2. **时间扩展 BFS 逃生**：格子会因炸弹消失而变安全，所以逃生搜索是"按回合"的：
   只有第 d 回合末没有火、且该格当时不是墙/砖/炸弹才允许通过。候选动作里不安全的一律重罚。
3. **必杀判定**：放弹/踢弹后对每个对手跑同一套 BFS，只要对手"从任意合法落点出发都逃不掉"，
   直接 +400 分优先执行（决赛/单挑权重更高）。
4. **潜力场进攻**：目标分 = 可炸砖数 + 附近道具价值（火力>加弹>踢弹，按自身上限折算）
   + 逼对手进死角 + 自由度 + "此处能安全放弹"奖励；对对手贴身做惩罚，避免被夹击。
   另有按座位独立的反停滞计数，防止两个强 bot 互相让格卡死。
5. **压墙**：按 seed 公开的 `crush_rotation` 自行重算整条螺旋（state 只预告 5 块），
   用 `next_crush` 校验后写进地形表，提前把落墙格当障碍、并惩罚站在近期会被压的位置。
6. 全程位运算，单步远低于 50ms CPU；最外层 try/except 兜底返回 `stay`。
